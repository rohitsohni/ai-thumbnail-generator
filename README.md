# AI Thumbnail Generator

A full-stack application for generating YouTube-style thumbnails from text prompts, adding title overlays, and exporting finished images.

## Project Highlights

- Built a React and TypeScript workflow for creating thumbnails from prompts and editing title overlays.
- Integrated Pollinations AI through a Node.js and Express API to generate thumbnail images.
- Used the Canvas API to position text overlays and export finished thumbnails.
- Added Sharp-based image processing and a local SVG fallback when the image provider fails.

## Tech Stack

React, TypeScript, Node.js, Express.js, Canvas API, Sharp
